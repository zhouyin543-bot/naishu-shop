## 💾 跨设备存档备份与本地运行

- **存档备份 / 换机恢复**：游戏进度自动保存在当前浏览器本地存储中。点击游戏右上角 **「设置」→「备份存档」** 即可一键复制 `NSHOP` 开头的存档码，粘贴到备忘录或发到新手机/电脑的 **「用存档码恢复」** 中即可无缝继承全部进度。
- **本地离线运行**：本仓库为纯静态零依赖单文件网页，克隆或下载仓库后直接双击打开 `index.html`（或使用任意静态服务器如 `python3 -m http.server 8000`）即可完整运行。
